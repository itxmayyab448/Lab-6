\# Calculator Program



\## Project Title

Simple Calculator Using Python



\## Purpose

The purpose of this project is to create a simple calculator program using Python. It demonstrates basic programming concepts and the use of Git for version control, including tracking changes, creating commits, and maintaining project history.



\## How to Run the Program

1\. Make sure Python is installed on your computer.

2\. Open Command Prompt or a terminal.

3\. Navigate to the project directory.

4\. Run the following command:



```bash

python cal.py

```
